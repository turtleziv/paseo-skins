COMMAND-LINE TOOL

不装客户端，
一条命令换肤。

面向程序员的开源 CLI。它负责主题完整性、Paseo 连接、持久 watcher 和一键还原；网页只负责预览与制作。

QUICK START

应用热门晨雾山水

需要 macOS 或 Windows、Paseo、Git 与 Node.js 22+。命令会在用户目录建立固定 checkout、安装依赖、校验主题清单与图片，并安装当前用户的持久 Guardian。

p="$HOME/paseo-skins"; { [ -d "$p/.git" ] || { [ ! -e "$p" ] && git clone https://github.com/huangguang1999/paseo-skins.git "$p"; }; } && [ "$(git -C "$p" remote get-url origin)" = "https://github.com/huangguang1999/paseo-skins.git" ] && npm ci --prefix "$p" && node "$p/src/cli.mjs" apply morning-mist --persist

CORE COMMANDS

完整工作流

以下命令在固定 checkout 根目录执行，Windows PowerShell 与 macOS Terminal 通用。

node ./src/cli.mjs list

列出公开目录中的主题。

node ./src/cli.mjs apply <theme-id> --persist

持久应用主题并自动恢复。

node ./src/cli.mjs inspect --theme …

离线检查清单与图片。

node ./src/cli.mjs create --image …

从图片制作主题包。

node ./src/cli.mjs verify --screenshot …

验证真实 renderer 并保存截图。

node ./src/cli.mjs autostart uninstall

移除自动恢复配置。

node ./src/cli.mjs reset

恢复原版 Paseo 样式。

为什么不是客户端？

本项目不需要另一个常驻 GUI。GitHub Pages 提供无权限的预览和 Studio；CLI 是可审查、可脚本化的本机执行层。两者都不会上传你的主题图片。

关闭终端也会自动恢复

--persist 会安装当前用户的 macOS LaunchAgents 或 Windows 登录任务。固定 checkout 请保留在用户目录；安装后可从该目录运行 node src/cli.mjs autostart uninstall 移除常驻。Paseo 若已运行且未启用本机 CDP，请完成工作后正常退出再打开。
